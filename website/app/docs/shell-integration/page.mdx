# Shell integration

## Quit into a directory

A program cannot change its parent shell's directory, so strata comes with a small shell function. Once it is installed, <Kbd>Q</Kbd> quits and leaves your shell in the directory you were browsing. Plain <Kbd>q</Kbd> leaves it where it was — or set `cd_on_quit = true` to always follow.

Add one line to your shell's config:

```sh
# bash — ~/.bashrc
eval "$(strata --shell-init bash)"

# zsh — ~/.zshrc
eval "$(strata --shell-init zsh)"
```

```fish
# fish — ~/.config/fish/config.fish
strata --shell-init fish | source
```

```powershell
# PowerShell — $PROFILE
Invoke-Expression (& strata --shell-init powershell | Out-String)
```

The function is called `strata` and wraps the real binary, so you keep typing `strata` as usual.

## Running commands

| Keys | Action |
| --- | --- |
| <Kbd>!</Kbd> | Open your `$SHELL` in the current directory (in a Docker container or over SSH for remote locations) |
| `:sh <command>` or `:!<command>` | Run a command here and see its output |
| `:each <command>` | Run a command once for each marked item |
| `:git <args>` | Run git here (from the `git` plugin) |

Commands can name the marked items (or the hovered one when nothing is marked) with placeholders. strata quotes them for the shell:

| Placeholder | Stands for |
| --- | --- |
| `{f}` | The first marked item's path |
| `{s}` | Every marked item's path |
| `{n}` | The first marked item's name |
| `{d}` | The current directory |

```text
:!tar czf backup.tgz {s}        one archive of everything marked
:each ffmpeg -i {f} {f}.mp3     one command per marked item
:each gzip -k                   no placeholder: the item goes at the end
```

Other braces, such as `{}` in `find -exec` or `{print $1}` in awk, are left as they are. Placeholders work on local folders only.

## Other flags

```text
strata [DIR...]           one panel per directory
  -c, --config <FILE>     use another config file
  -t, --theme <THEME>     override the theme
      --no-plugins        start without plugins
      --list-themes       print every theme
      --dump-config       print a documented config
      --shell-init <SH>   print the shell function (bash, zsh, fish, powershell)
      --chooser-file <F>  pick files for another program (see below)
```

## Picking files from other programs

`strata --chooser-file <file>` turns strata into a file picker: <Kbd>enter</Kbd> on a file (or on anything, once items are marked with <Kbd>space</Kbd>) writes the chosen paths to `<file>`, one per line, and quits. Quitting without choosing leaves the file untouched. Editors such as Neovim can use this the way they use yazi or ranger:

```sh
strata --chooser-file /tmp/chosen && cat /tmp/chosen
```
