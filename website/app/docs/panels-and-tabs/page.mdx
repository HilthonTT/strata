# Panels & tabs

## Panels

strata opens two panels by default (`panels = 2` in the config). Each panel has its own directory, history, sort order, filter and marks.

| Keys | Action |
| --- | --- |
| <Kbd>tab</Kbd> / <Kbd>shift+tab</Kbd> | Focus the next / previous panel |
| <Kbd>n</Kbd> | Open a new panel (up to six) |
| <Kbd>ctrl+w</Kbd> | Close the focused panel |
| <Kbd>H</Kbd> / <Kbd>L</Kbd> | Back / forward in the panel's history |
| <Kbd>ctrl+h</Kbd> / <Kbd>ctrl+l</Kbd> | Focus the sidebar / go back to the panels |
| <Kbd>c</Kbd> / <Kbd>m</Kbd> | Copy / move the marked items into the next panel |

The focused panel has a coloured border. Its bottom border shows the mode — **Browser**, or **Select** while items are marked — and your position, such as `3/24`.

## Tabs

Tabs keep whole workspaces apart: every tab has its own panels.

| Keys | Action |
| --- | --- |
| <Kbd>t</Kbd> | New tab at the current directory |
| <Kbd>g t</Kbd> / <Kbd>g T</Kbd> | Next / previous tab |
| <Kbd>alt+1</Kbd> … <Kbd>alt+9</Kbd> | Go to tab 1–9 |
| <Kbd>g q</Kbd> | Close the tab |

Open tabs are listed in the top bar. With the classic preset, use <Kbd>ctrl+t</Kbd>, <Kbd>alt+←</Kbd> / <Kbd>alt+→</Kbd> and <Kbd>alt+w</Kbd>.

## The sidebar

The sidebar lists well-known places, your pinned directories, mounted disks and NAS connections. Press <Kbd>P</Kbd> to pin or unpin the current directory; pins are remembered between sessions. Click any entry, or focus the sidebar with <Kbd>ctrl+h</Kbd> and press <Kbd>enter</Kbd>.

## Live refresh

Panels showing a local folder update by themselves when files change — whether strata or another program changed them. Bursts of changes, such as a large copy or a `git checkout`, are combined into one refresh. Press <Kbd>F5</Kbd> to reload everything by hand, for example on network drives that do not report changes.

SFTP and Docker folders load in the background, so a slow server never freezes the screen; the panel shows **loading…** until the listing arrives.

## Mouse

Click to focus a panel and move the cursor, double-click to open, and scroll anywhere.
