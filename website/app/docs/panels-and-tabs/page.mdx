# Panels & tabs

## Panels

strata opens two panels by default (`panels = 2` in the config). Each panel has its own directory, history, sort order, filter and marks.

| Keys | Action |
| --- | --- |
| <Kbd>tab</Kbd> / <Kbd>shift+tab</Kbd> | Focus the next / previous panel |
| <Kbd>n</Kbd> | Open a new panel (up to six) |
| <Kbd>ctrl+w</Kbd> | Close the focused panel |
| <Kbd>H</Kbd> / <Kbd>L</Kbd> | Back / forward in the panel's history |
| <Kbd>ctrl+h</Kbd> / <Kbd>ctrl+l</Kbd> | Focus the sidebar / go back to the panels |
| <Kbd>c</Kbd> / <Kbd>m</Kbd> | Copy / move the marked items into the next panel |

The focused panel has a coloured border. Its bottom border shows the mode — **Browser**, **Tree**, or **Select** while items are marked — and your position, such as `3/24`.

## Tree view

Press <Kbd>z t</Kbd> (<Kbd>alt+t</Kbd> with the classic preset), or run `:tree`, to show the panel's folder as a tree. Folders open in place instead of being entered:

| Keys | Action |
| --- | --- |
| <Kbd>l</Kbd> / <Kbd>enter</Kbd> | Expand or collapse the folder |
| <Kbd>h</Kbd> | Collapse the folder, or jump to the folder holding the item; at the top level, go to the parent directory |
| <Kbd>z M</Kbd> | Collapse everything |

New files, new folders and pastes go inside the hovered folder when it is expanded, and next to the hovered item otherwise. Marks, file operations, git markers and folder sizes work across the whole tree. The filter matches paths relative to the panel's folder and lists matches flat. Expanded folders are watched for changes too, and the tree works on remote connections, where each folder loads in the background.

## Hide files ignored by git

Press <Kbd>z i</Kbd> (<Kbd>alt+i</Kbd> with the classic preset), or run `:set gitignored`, to leave out everything git ignores — build output such as `target/` or `node_modules/`, logs, and whatever your `.gitignore` files, `.git/info/exclude` and global excludes file list. Tracked files always stay. It works in the list, the tree view and flat listings of local folders, and the status line says `gitignored hidden` while it is on. Set `hide_gitignored = true` to start that way.

strata asks git itself (`git check-ignore`, once per repository and listing, off the UI thread), so the answer always matches what git does.

## Tabs

Tabs keep whole workspaces apart: every tab has its own panels.

| Keys | Action |
| --- | --- |
| <Kbd>t</Kbd> | New tab at the current directory |
| <Kbd>g t</Kbd> / <Kbd>g T</Kbd> | Next / previous tab |
| <Kbd>alt+1</Kbd> … <Kbd>alt+9</Kbd> | Go to tab 1–9 |
| <Kbd>g q</Kbd> | Close the tab |

Open tabs are listed in the top bar. With the classic preset, use <Kbd>ctrl+t</Kbd>, <Kbd>alt+←</Kbd> / <Kbd>alt+→</Kbd> and <Kbd>alt+w</Kbd>.

Set `restore_session = true` to reopen your tabs, folders, sort orders, tree views and cursor positions from the last time you quit whenever you start strata without paths. Remote panels are not reopened; a folder that no longer exists opens at its nearest parent.

### Layouts

A layout is a set of tabs and panels saved under a name, so you can keep one for each project or task:

| Command | What it does |
| --- | --- |
| `:layout save <name>` | Save the open tabs and local panels (asks before replacing a layout of that name) |
| `:layout load <name>` | Replace the open tabs with the layout |
| `:layout list` | Pick a layout: <Kbd>enter</Kbd> opens it, <Kbd>ctrl+d</Kbd> deletes it |
| `:layout delete <name>` | Delete a layout |
| `:layout rename <name> <new>` | Rename a layout |

Names are one word; <Kbd>tab</Kbd> completes them. Start strata with `strata --layout <name>` to open one straight away, or set `default_layout = "<name>"` to open it whenever you start without paths. What opens at start, first match wins: `--layout`, then the paths you give, then `default_layout`, then `restore_session`. `--layout` and paths can't be combined, and a missing `--layout` stops strata with an error, while a missing `default_layout` only warns. Layouts are kept in `layouts.json` in the data directory.

## Folder sizes

Press <Kbd>d c</Kbd> (<Kbd>alt+d</Kbd> with the classic preset), run `:set dir_sizes`, or set `dir_sizes = true` to show how much each folder holds. Sizes are measured in the background without leaving the folder's disk and fill in as they finish; sorting by size then orders folders by them too. They are measured again when files change.

With `extra_columns` you can also show the modified date (in your `date_format`) and permissions next to each name.

## The sidebar

The sidebar lists well-known places, your pinned directories, mounted disks (removable ones marked with an eject icon), NAS connections and your [tags](/docs/file-operations/#tags). Press <Kbd>P</Kbd> to pin or unpin the current directory; pins are remembered between sessions. Click any entry, or focus the sidebar with <Kbd>ctrl+h</Kbd> and press <Kbd>enter</Kbd>.

## Live refresh

Panels showing a local folder update by themselves when files change — whether strata or another program changed them. Bursts of changes, such as a large copy or a `git checkout`, are combined into one refresh. Press <Kbd>F5</Kbd> to reload everything by hand, for example on network drives that do not report changes.

SFTP, Docker and rclone (S3, WebDAV, FTP…) folders load in the background, so a slow server never freezes the screen; the panel shows **loading…** until the listing arrives.

## Mouse

Click to focus a panel and move the cursor, double-click to open, and scroll anywhere.
