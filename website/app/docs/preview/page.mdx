# Preview & metadata

The preview on the right follows the cursor. Toggle it with <Kbd>w</Kbd>.

## Scrolling and searching

| Keys | Action |
| --- | --- |
| <Kbd>alt+j</Kbd> / <Kbd>alt+k</Kbd> (or <Kbd>alt+↓</Kbd> / <Kbd>alt+↑</Kbd>) | Scroll half a page |
| Mouse wheel over the preview | Scroll |
| <Kbd>alt+/</Kbd> | Search inside the preview |
| <Kbd>alt+n</Kbd> / <Kbd>alt+N</Kbd> | Next / previous match |

Matching lines are highlighted, and the bottom corner shows which lines you are looking at. The preview holds up to 5,000 lines of a file (the first 1 MB); syntax colours cover the first 2,000.

| Item | Preview |
| --- | --- |
| Directories | Their contents, with icons |
| Source code | Syntax highlighting coloured from your theme |
| Markdown | Rendered: headings, lists, task boxes, quotes, tables, links and code blocks with syntax colours |
| Images | PNG, JPEG, GIF, WebP, BMP and ICO |
| Archives | The list of files (via the `archive` plugin) |
| Binary files | Size, and a hint to open them with the system app |

Images use the best protocol your terminal supports — kitty, sixel or iTerm2 — and a half-block approximation everywhere else.

Rendered Markdown is wrapped to the preview's width. To see the highlighted source instead:

```toml
[general]
markdown_preview = false
```

```toml
[general]
preview = true
image_preview = true
syntax_highlight = true
preview_border = false   # superfile-style borderless preview
line_numbers = false
```

## Metadata

The **Metadata** box in the footer shows the hovered item's name, type, size, modification date, permissions and path. For executables it also shows the architecture — for example `ELF 64-bit x86-64`, `PE32+ ARM64` or `Mach-O 64-bit arm64`.

Turn on `md5_checksum = true` or `sha256_checksum = true` to see each file's MD5 or SHA-256 as well (<Kbd>#</Kbd> shows them on demand, see [checksums](/docs/file-operations/#checksums)). It is computed in the background and stops as soon as you move on, so large files never slow you down.
