# Key bindings

Press <Kbd>?</Kbd> inside strata to see every key, including those added by plugins.

## Presets

strata ships two layouts. Choose one with `keymap` under `[general]`:

- **`vim`** (default) — `h j k l`, sequences like <Kbd>g g</Kbd>, <Kbd>y y</Kbd> and <Kbd>d d</Kbd>.
- **`default`** — superfile-style: <Kbd>ctrl+c</Kbd> copy, <Kbd>ctrl+x</Kbd> cut, <Kbd>ctrl+v</Kbd> paste, <Kbd>ctrl+d</Kbd> delete, <Kbd>ctrl+n</Kbd> create, <Kbd>ctrl+r</Kbd> rename, <Kbd>ctrl+z</Kbd> undo, <Kbd>o</Kbd> sort menu and no multi-key sequences.

| Action | vim | default |
| --- | --- | --- |
| Copy / cut / paste | <Kbd>y y</Kbd> <Kbd>x</Kbd> <Kbd>p</Kbd> | <Kbd>ctrl+c</Kbd> <Kbd>ctrl+x</Kbd> <Kbd>ctrl+v</Kbd> |
| Trash / delete | <Kbd>d d</Kbd> / <Kbd>D</Kbd> | <Kbd>ctrl+d</Kbd> / <Kbd>D</Kbd> |
| Rename / bulk rename | <Kbd>r</Kbd> / <Kbd>R</Kbd> | <Kbd>ctrl+r</Kbd> / <Kbd>alt+r</Kbd> |
| New file / directory | <Kbd>a</Kbd> / <Kbd>A</Kbd> | <Kbd>ctrl+n</Kbd> (end the name with `/` for a directory) |
| Undo / redo | <Kbd>u</Kbd> / <Kbd>ctrl+r</Kbd> | <Kbd>ctrl+z</Kbd> / <Kbd>ctrl+y</Kbd> |
| Sort menu | <Kbd>s</Kbd> | <Kbd>o</Kbd> |
| Fuzzy find | <Kbd>f</Kbd> | <Kbd>ctrl+f</Kbd> |
| Toggle preview | <Kbd>w</Kbd> | <Kbd>f</Kbd> |
| New tab | <Kbd>t</Kbd> | <Kbd>ctrl+t</Kbd> |
| Copy path / current directory | <Kbd>y p</Kbd> / <Kbd>y d</Kbd> | <Kbd>ctrl+p</Kbd> / <Kbd>c</Kbd> |

Both presets share <Kbd>F5</Kbd> (refresh), <Kbd>alt+j</Kbd> / <Kbd>alt+k</Kbd> (scroll the preview), <Kbd>alt+/</Kbd> (search the preview), <Kbd>tab</Kbd>, the arrow keys, <Kbd>/</Kbd>, <Kbd>.</Kbd>, <Kbd>:</Kbd>, <Kbd>?</Kbd>, <Kbd>T</Kbd>, <Kbd>1</Kbd>–<Kbd>4</Kbd>, <Kbd>ctrl+g</Kbd>, <Kbd>e</Kbd>, <Kbd>E</Kbd>, <Kbd>q</Kbd> and <Kbd>Q</Kbd>.

## Remapping

Map keys to an action name, to a `:command`, or to `"none"` to unbind them:

```toml
[keys]
"ctrl+e" = "edit"
"g p" = ":cd ~/projects"
"g w" = ":theme rose-pine"
"x" = "none"
```

Keys are written as `j`, `G`, `space`, `enter`, `esc`, `tab`, `backtab`, `backspace`, `delete`, `up`, `pageup`, `home`, `f5`, with `ctrl+`, `alt+` or `shift+` in front. Separate keys in a sequence with spaces. Your mappings override both the preset and plugins.
