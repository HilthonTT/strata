# File operations

<Media src="file-operations.gif" alt="Copying, renaming, trashing and undoing" caption="Copy to the next panel, rename, undo, trash and undo again." />

Most actions apply to the **marked** items, or to the item under the cursor when nothing is marked. Mark with <Kbd>space</Kbd>, select a range with <Kbd>v</Kbd>, extend with <Kbd>J</Kbd> / <Kbd>K</Kbd>, mark everything with <Kbd>ctrl+a</Kbd> or by pattern with `:select *.png`.

## Copy and move

| Keys | Action |
| --- | --- |
| <Kbd>y y</Kbd> / <Kbd>x</Kbd> then <Kbd>p</Kbd> | Copy / cut, then paste in another directory |
| <Kbd>c</Kbd> / <Kbd>m</Kbd> | Copy / move straight into the next panel |

If some names already exist in the destination, strata asks once for the whole paste: **keep both** (the new item becomes `name (1).ext`), **overwrite** (replaced items go to the trash on local disks), **skip** those items, or cancel.

Transfers run in the background, so you can keep working. Their progress appears under **Processes** in the footer; <Kbd>ctrl+x</Kbd> cancels the latest one. Copies work between any locations — local disk, SFTP servers and Docker containers.

## Create, rename, delete

| Keys | Action |
| --- | --- |
| <Kbd>a</Kbd> / <Kbd>A</Kbd> | New file / directory (`docs/notes.md` creates the folder too) |
| <Kbd>r</Kbd> | Rename |
| <Kbd>R</Kbd> | Bulk rename the marked items in `$EDITOR` |
| <Kbd>d d</Kbd> | Move to the trash |
| <Kbd>D</Kbd> | Delete permanently |

Bulk rename opens one name per line in your editor; change the lines, save and quit. Swapping two names works, and strata refuses to overwrite files that are not part of the rename.

## Duplicate and link

| Keys | Action |
| --- | --- |
| <Kbd>Y</Kbd> | Duplicate the marked items next to themselves (`name (1).ext`) |
| <Kbd>g l</Kbd> / `:link` | Paste the clipboard as symbolic links |
| <Kbd>g L</Kbd> / `:link -r` | Paste the clipboard as relative symbolic links (`../lib/x`) |
| `:hardlink` | Paste the clipboard as hard links |

Links are made in the focused directory to what you copied with <Kbd>y y</Kbd>, and get a ` (1)` suffix when the name is taken. Symbolic links work on the local disk, SFTP servers and in Docker containers; hard links on the local disk and in containers.

## Permissions and owners

<Kbd>=</Kbd> asks for new permissions for the marked items, starting from the hovered item's current mode. Type an octal mode (`644`, `2755`) or a symbolic one like `chmod` takes (`u+x`, `go-w`, `a=rX`, `u=rwx,go=rx`). Start with `-R` to change everything below directories too; symbolic links met on the way are left alone. The same works as `:chmod [-R] <mode>`.

`:chown [-R] user[:group]` (or `:group`) changes the owner of local items. Names are looked up the way `id` and `getent` do, so LDAP users work too. Changing owners usually needs root.

## Compare

<Kbd>C</Kbd> compares two items:

- two **marked** items in the same panel, or
- the hovered item with the item of the same name in the next panel (or, if there is none, the item hovered there).

Two text files open as a coloured unified diff. Binary or large files (over 4 MiB) only report whether they differ. Two directories are compared recursively: the report lists what differs and what exists on one side only. Comparisons run in the background and work across local, SFTP and Docker locations.

To use your own diff tool for local files, set it in the config:

```toml
[general]
diff_tool = "nvim -d"   # or "meld", "code --diff --wait", "delta"…
```

## Undo and redo

Press <Kbd>u</Kbd> (or <Kbd>ctrl+z</Kbd> with the classic preset) to undo the last operation, and <Kbd>ctrl+r</Kbd> (<Kbd>ctrl+y</Kbd>) to redo it. Doing something new clears what can be redone. Undo covers:

- renames and bulk renames,
- new files and directories (they go to the trash),
- copies (the copies go to the trash),
- moves (items go back where they came from, even across filesystems),
- trashing (items are restored from the trash — Linux and Windows),
- links and duplicates (they go to the trash),
- permission and owner changes (the old ones are set again).

<Callout type="warn">Permanent deletes (<Kbd>D</Kbd>) cannot be undone. strata asks for confirmation unless you set `confirm_delete = false`.</Callout>

## Open files

<Kbd>enter</Kbd> opens text files in your editor and media or documents with the system app. <Kbd>o</Kbd> always uses the system app, and <Kbd>e</Kbd> / <Kbd>E</Kbd> open the file or the whole directory in your editor. To choose programs per file type, see [`open_with`](/docs/configuration/#open-with).

## Remote files

On SFTP servers and in Docker containers, <Kbd>enter</Kbd> and <Kbd>e</Kbd> download the file to a private temporary folder and open it in your editor. When you quit the editor, strata uploads the file back if you changed it, then deletes the copy.
